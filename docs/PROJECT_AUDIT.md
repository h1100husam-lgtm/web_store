# تقرير فحص مشروع Reda Store

> تاريخ الفحص: 2026-09-24 — الفرع: `arena/01a0d16b-web-store`

## 1) الوضع الحالي للمشروع

المشروع **متجر إلكتروني ثابت (Static Front-end)** مبني بـ HTML + CSS + JavaScript خام، بدون أي سيرفر أو قاعدة بيانات.

| الملف | الوظيفة | الحالة |
|---|---|---|
| `index.html` | الصفحة الرئيسية + الهيدر + الفوتر + السايدبار (السلة) + 4 سلايدرات منتجات | يعمل بصرياً |
| `checkout.html` | ملخص الطلب + نموذج بيانات التوصيل + نافذة نجاح الطلب | يعمل جزئياً (بدون حفظ) |
| `products.json` | 25 منتج (id, img, name, price, old_price, catetory) | يعمل — فيه خطأ إملائي باسم الحقل |
| `CSS/style.css` | 1450 سطر تنسيقات | مكتمل للصفحتين الموجودتين فقط |
| `JS/main.js` | السلة (localStorage) + ملخص الطلب + إرسال النموذج | يعمل على المتصفح فقط |
| `JS/items_home.js` | بناء بطاقات المنتجات داخل السلايدرات | يعمل، مع تكرار كود كبير |
| `JS/swiper.js` | تهيئة مكتبة Swiper | يعمل |
| `Code gs.txt` | بقايا Google Apps Script (POST إلى Google Sheet) | غير مستخدم إطلاقاً |
| `img/` | الشعارات والبانرات وصور المنتجات | مكتمل |

**ملاحظة تشغيلية مهمة:** الموقع لا يعمل أبداً عند فتح `index.html` مباشرة من نظام الملفات (`file://`) لأن `fetch('products.json')` يُحجب بـ CORS. يحتاج دائماً لسيرفر محلي — وهذا غير موجود حالياً (لا `package.json`، لا تعليمات تشغيل).

## 2) النواقص (مرتبة حسب الأهمية)

### أ. نواقص تمنع العمل كمتجر حقيقي

1. **لا يوجد سيرفر محلي** — لا `package.json`، لا سكربت تشغيل، لا README.
2. **تسجيل الدخول / إنشاء حساب غير موجود نهائياً** — زرّا `Login` و `Sign UP` في الهيدر روابط ميتة (`href="#"`). لا توجد: صفحات مصادقة، جدول مستخدمين، جلسات (sessions)، حماية للصفحات.
3. **لا قاعدة بيانات** — كل شيء في `localStorage`، أي:
   - السلة تضيع عند تغيير المتصفح/الجهاز ولا ترتبط بالمستخدم.
   - **الطلبات لا تُحفظ أبداً**: يظهر modal نجاح ثم تُمسح السلة وتنتهي القصة — لا سجل طلبات ولا إمكانية مراجعتها.
4. **الأسعار تُحسب في المتصفح** — يمكن لأي شخص تعديل السعر من أدوات المطور وتمرير طلب بسعر خاطئ (لا تحقق من جهة السيرفر).

### ب. ميزات واجهة موجودة شكلاً ومعطّلة وظيفياً

5. **البحث** — نموذج البحث `action=""`؛ الضغط على Enter يعمل reload للصفحة فقط، ولا توجد صفحة نتائج بحث ولا تصفية.
6. **المفضلة (Wishlist)** — أيقونة القلب والعدّاد `count_favourite` موجودان في الهيدر + زر قلب في كل منتج، لكن لا وظيفة ولا صفحة مفضلة ولا تخزين.
7. **صفحة تفاصيل المنتج** — اسم المنتج وصورته كلها `href="#"`؛ لا توجد صفحة تفاصيل (وصف، مواصفات، تقييمات، منتجات مشابهة).
8. **التصنيفات** — قائمة "Browse Category" وكل روابطها `href="#"`؛ لا صفحة تصفية حسب التصنيف.
9. **روابط التنقل** — About / Accessories / Blog / Contact كلها `#` غير موجودة.
10. **الفوتر** — كل روابطه (Your Account، Purchase History، الدعم، السياسات) ميتة.

### ج. ثغرات وجودة كود

11. **XSS**: استخدام `innerHTML` مع بيانات غير مُهرَّبة (أسماء المنتجات، وبيانات نموذج الـ checkout مثل الاسم والعنوان تُعرض داخل modal مباشرة).
12. **لا تحقق من المدخلات** (server-side validation) ولا حماية من brute-force على الدخول (rate limiting).
13. **تكرار كود**: `products.json` يُجلب مرتين (في `main.js` و `items_home.js`)، وكود بناء بطاقة المنتج مكرر 4 مرات نصاً في `items_home.js`.
14. **أخطاء إملائية في الكود** ستربك أي توسعة لاحقة: `catetory` (بدل `category`)، `updateButoonsState`، `dynamicBullests`، `price_cart_toral`.
15. **اعتماد على CDN خارجي** (Swiper، Font Awesome، Google Fonts) — الموقع يتكسر جزئياً بدون إنترنت.
16. **لا يوجد**: `.gitignore`، صفحة 404، meta description / SEO، اختبارات، أو إدارة بيئة (`.env`).

## 3) الخطة المقترحة (على مراحل)

| المرحلة | المحتوى |
|---|---|
| **1. بيئة محلية** | Node.js + Express يخدم الصفحات + SQLite (ملف واحد، بدون تنصيب قاعدة بيانات) + `npm run dev/start` + README عربي + `.gitignore` + `.env.example` + صفحة 404 |
| **2. المصادقة** | صفحات Login / Sign Up، تشفير كلمة المرور (bcrypt)، جلسات بكوكيز `httpOnly`، زر خروج، صفحة "حسابي"، حماية الـ checkout، عرض اسم المستخدم في الهيدر |
| **3. إكمال المتجر** | صفحة تفاصيل المنتج، البحث الحقيقي + صفحة نتائج، التصفية حسب التصنيف، المفضلة مربوطة بالسيرفر + صفحتها |
| **4. الطلبات** | حفظ الطلب في SQLite بأسعار من السيرفر، سجل طلبات المستخدم، حالات الطلب (قيد التجهيز/مشحون/مكتمل) |
| **5. لوحة تحكم** | أدمن: إدارة المنتجات (CRUD)، عرض الطلبات وتغيير حالتها، إحصائيات بسيطة |
| **6. تنظيف وأمان** | توحيد كود بطاقة المنتج في مكوّن واحد، تهرُّب HTML، validation، rate limiting، تنزيل مكتبات CDN محلياً (offline) |

**نفس التصميم الحالي سيبقى كما هو** (نفس الألوان `--main_color: #ff8716` ونفس الخطوط)، وستُبنى الصفحات الجديدة على نفس الـ CSS الموجود مع إضافات مكمّلة.
