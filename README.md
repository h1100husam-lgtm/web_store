# Reda Store — متجر إلكتروني (واجهة أمامية فقط)

مشروع متجر بسيط مبني بـ **HTML + CSS + JavaScript** فقط، بدون أي سيرفر أو قاعدة بيانات.
كل شيء (تسجيل الدخول، السلة، المفضلة، الطلبات) **محاكاة وهمية** شغّالة في المتصفح عبر `localStorage`.

---

## 1) التشغيل على بيئة محلية

المشروع يحتاج Node.js فقط (بدون تنصيب أي مكتبة).

```bash
# من داخل مجلد المشروع
npm start
# أو
node server.js
```

بعدها افتح المتصفح على:

```
http://localhost:3000
```

لتغيير المنفذ:

```bash
PORT=8080 npm start        # Linux / Mac
set PORT=8080 && npm start # Windows
```

### طرق أخرى للتشغيل (بدون Node)

| الطريقة | الأمر |
|---|---|
| Python 3 | `python3 -m http.server 3000` |
| VS Code | إضافة **Live Server** ← زر "Go Live" |
| XAMPP | ضع المجلد داخل `htdocs` وافتح `http://localhost/web_store` |

> ⚠️ لا تفتح `index.html` مباشرة بضغطة مفتوحة (`file://`) — بعض الميزات ما تشتغل بهذه الطريقة.

## 2) حساب تجريبي جاهز

| البريد | كلمة المرور |
|---|---|
| `demo@redastore.com` | `123456` |

## 4) كيف تـُخزَّن البيانات (محاكاة فقط)

كل شيء داخل `localStorage` بالمتصفح:

| المفتاح | يحتوي |
|---|---|
| `reda_users` | المستخدمون المسجّلون |
| `reda_session` | المستخدم الحالي (الجلسة) |
| `reda_cart` | السلة |
| `reda_wishlist` | المفضلة |
| `reda_orders` | الطلبات |
| `reda_addresses` | العناوين المحفوظة |

لمسح كل شيء والعودة من البداية:

```js
// في الـ Console بالمتصفح
localStorage.clear();
```

> ⚠️ كلمات المرور محفوظة كما هي (نص عادي) عن قصد، لأن المشروع تجريبي تعليمي.
> في مشروع حقيقي لازم تكون مُشفّرة (hash) ويسويها سيرفر، مش المتصفح.

## 5) الميزات الشغّالة

- تصفّح المنتجات في الرئيسية عبر سلايدرات (Hot Deals / Electronics / Appliances / Mobiles / New Arrivals)
- صفحة متجر كاملة: فلترة حسب التصنيف والسعر والعروض + ترتيب (الأرخص، الأعلى تقييم، الأحدث، الاسم)
- صفحة تفاصيل المنتج: المواصفات، التقييمات، إضافة تقييم، منتجات مشابهة
- بحث حقيقي يبحث في الاسم والوصف والكلمات المفتاحية والتصنيف
- سلة جانبية + صفحة سلة (زيادة/تقليل الكمية/حذف) مع حساب المجموع والشحن
- تسجيل دخول وإنشاء حساب + خروج + قائمة مستخدم في الهيدر
- صفحة حسابي: تعديل البيانات + إحصائيات (عدد الطلبات، إجمالي الشراء، المفضلة)
- المفضلة (قلب على كل منتج) + صفحتها
- إتمام الطلب: التحقق من الحقول، **إعادة قراءة الأسعار من `JS/data.js`**، حفظ الطلب، نافذة نجاح
- صفحة طلباتي: حالة الطلب، التفاصيل، زر "إعادة الطلب"
- إشعارات (Toast) + تصميم متجاوب مع الجوال

---

## 6) ملاحظات للنقاش (HTML / CSS)

- `CSS/style.css` هو نظام التصميم: متغيّرات الألوان في `:root`، ثم الهيدر، السلايدرات، المنتجات، السلة، الفوتر.
- `CSS/pages.css` يُحمَّل **بعد** `style.css` ويعيد استخدام نفس المتغيّرات (`--main_color`, `--p_color`, `--bg_color`, `--border_color`).
- المحتوى المتكرر (الهيدر/الفوتر/السلة الجانبية) مكتوب في كل صفحة — عادي في المشاريع الساكنة بدون قوالب.
- كل شيء في الموقع إنجليزي؛ `index.html` يحتوي أمثلة على `&amp;` (HTML entities) في الروابط.
