Who we are

Reda Store is a front-end demo project built with HTML, CSS and JavaScript. It shows a complete online shopping experience - browsing, searching, filtering, a cart, a wishlist, accounts, login and checkout - without any server or database.

Everything you see is stored locally in your browser using localStorage, so you can experiment freely: create an account, place orders, and reset any time by clearing the browser storage.
